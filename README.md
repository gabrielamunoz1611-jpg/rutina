# 🏋️ FitRoutine Cloud

Aplicación web progresiva diseñada para crear, gestionar y ejecutar rutinas de ejercicio personalizadas por usuario, con soporte para almacenamiento persistente y videos demostrativos integrados.

## 🚀 Características Principales
- **Registro Multi-usuario:** Permite registrar un nombre para guardar y cargar las rutinas de diferentes personas de forma independiente.
- **Creador Dinámico de Rutinas:** Configura múltiples días de entrenamiento y añade los ejercicios necesarios para cada uno.
- **Generación Automática de Descripciones:** Crea automáticamente una guía técnica de ejecución paso a paso analizando el nombre del ejercicio y el video base adjunto.
- **Reproductor Interactivo con Control de Velocidad:** Visualiza el video de demostración y ajusta su velocidad de reproducción (de 0.5x a 2.0x) en tiempo real mientras entrenas.
- **Persistencia en la Nube / LocalStorage:** Guarda los perfiles, rutinas y videos directamente en el almacenamiento web del navegador para acceder a ellos sin servidores externos.

## 📱 ¿Cómo usarla?
Puedes probar la aplicación directamente desde la web desplegada o clonar el repositorio y abrir el archivo `index.html` en cualquier navegador moderno desde tu computadora o teléfono celular.
